Flashfire Privacy

Flashfire is an offline single-player game. It does not create accounts, send analytics, show ads, or transmit gameplay data.

In the standalone game, progress, settings, records, and challenges are stored only in this browser using local storage. When hosted in UTXOPlay’s isolated game window, they last for the current visit and reset on reload. Standalone exported save files leave the browser only when you choose where to save or share them.
